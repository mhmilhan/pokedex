For me..I would definitely go with a cloud-based solution. Actually I don't have much experience setting up serevers. I honestly don't want to deal with the hassle of maintaining a physical server or managing the operating system updates myself. It feels much safer to let a dedicated provider handle the infrastructure for me so my team can focus entirely on the code. Let's assume we are using Python for this application. For linting, I would use Pylint to catch errors and probably Black to format the code automatically. This way, everyone's code looks the same when they save it. For testing, I guess Pytest is the standard tool. Before a developer commits their code, they should run pytest locally to make sure everything passes. Then, when they push the code to the cloud, the CI system will build the project, maybe using Docker, and run the tests again to be sure.I would probably choose CircleCI or maybe GitHub Actions itself because they are easy to connect to the repository online. Since I don't want to deal with hardware updates or security patches on a real server, the cloud solution is definitely the best choice for me and my team to move fast.
